# Apple-Artwork-Explorer
A Python/Streamlit application for searching Apple media metadata and discovering high-resolution artwork resources across iTunes and Apple TV services.

## Features

- Keyword-based media search
- High-resolution artwork retrieval
- Apple Music album metadata lookup
- Apple TV URL lookup
- Season artwork discovery
- Multi-country storefront support
- Streamlit web interface
